# LinzinDeskClock 2.0.4 使用說明

## 一般手機自動桌面時鐘

1. 從歡迎頁的「設定自動桌面時鐘」或時鐘設定開啟監看。
2. 選擇充電條件；新安裝預設不要求充電，既有選擇會保留。
3. 若要從其他 App 鎖定後自動顯示，啟用對應選項，閱讀說明，再到系統授予「顯示在其他應用程式上層」。程式不建立覆蓋視窗。
4. 將手機橫放在支架上、相對桌面傾斜 30°–75°，再鎖定。掃描最多 5 秒，需連續穩定約 1.5 秒；旋轉或插電本身不會啟動時鐘。
5. 背景權限不足或廠商限制自動啟動時，可使用通知備援。通知權限被拒絕時，從設定前往系統通知頁調整。

監看可在離開主畫面後繼續；已啟用的監看可在系統服務重啟或開機後恢復。開機本身不會掃描或顯示時鐘。強制停止後需手動重新開啟並恢復監看，部分廠商也要求額外的背景／自動啟動設定。

摺疊機仍採原有 30°–120° 鉸鏈觸發；這與一般手機傾角是不同條件。

## 版面、媒體與退出

- 分隔線可拖曳至 20%–80%；放開於 30／50／70% 附近 ±5 百分點時吸附。
- 左／右側由使用者選擇；跨越中央仍保留選擇，比例及側別各自保存。
- 媒體頁缺少權限時，點「前往通知存取權」進入系統設定。授權後顯示系統媒體工作階段及其支援的控制。
- 鎖定時保留曲名、演出者、封面及進度，也可使用已授權的媒體控制。UI Lock 是另外的互動鎖，開啟後停用媒體及版面操作；進入系統設定仍需解鎖。
- 媒體控制面板約占頁面高度 35%，適應短畫面與大字體；進度點與軌道共用繪製／互動座標。
- 右上角退出及底部向上長滑可關閉時鐘，UI Lock 不會封鎖出口。手動退出後，同一鎖定週期不再自動開啟。

## 行程與低電量保護

點擊行程可查看完整標題、時間、地點、行事曆與說明，也可前往系統行事曆的對應時段。裝置鎖定、UI Lock 或權限撤回時，詳細內容不可繼續操作。

低電量保護可選擇門檻與「降低亮度」或「退出」。只有未接電且低於門檻時觸發；降亮度上限為 8%，原本更暗的設定仍保留。退出會停止時鐘與監看，避免同一低電量條件反覆開啟。

## 閒置關屏與防烙印

選擇有限逾時後，可明確啟用「僅鎖定」裝置管理員，讓逾時呼叫系統鎖定並關屏。未授權時會退出時鐘及釋放保持喚醒，由系統螢幕逾時處理；不會用黑色畫面假裝關屏。詳見 [閒置關屏](screen-off-timeout.md)。

防烙印開啟時，API 33 以上於閒置 60 秒後套用棋盤格遮黑，每 5 分鐘交換像素，涵蓋媒體封面及控制。觸碰會重設，媒體進度更新不會重設。API 31–32 略過此效果；這不是長期 OLED 耐久保證。

## 系統螢幕保護程式

可在 Android 螢幕保護程式選擇本 App。DreamService 與監看共用符合條件的鎖定掃描；太晚啟動、沒有有效鎖定事件或姿勢不符時會結束。各廠商可能不提供或限制此入口。
