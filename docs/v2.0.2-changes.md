# 2.0.2 功能調整

- 鎖定畫面完整顯示媒體曲名、演出者、封面及進度，保留已授權的播放控制；UI Lock 另外停用操作。
- 控制面板約占頁面 35% 高度，修正內部圓角黑邊。進度點、軌道、拖曳及點擊共用幾何計算，支援 RTL、鍵盤與無障礙操作。
- 底部退出區縮為 12 dp，提示線高 2 dp。
- 行程可展開詳細資訊，並以正確 occurrence 開啟外部行事曆。
- 新增低電量門檻及降亮度／退出選項，充電時不觸發，不修改系統亮度。
- API 33 以上的防烙印效果涵蓋媒體控制區，以隔離模擬器的實際 MediaSession 與 PixelCopy 測試驗證。

測試程式及限制見 [模擬器驗證](emulator-testing.md)。
