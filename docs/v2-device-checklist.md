# 裝置驗收清單

此表是待執行的真機驗收，不表示已測試通過。自動化 JVM、模擬器與真機證據必須分開記錄。下列項目須由裝置擁有者自行驗收；未勾選不代表已通過。

## 一般手機與鎖定週期

- [ ] Android 12、14、15、16、17；至少 Pixel/AOSP 與一種 OEM 省電環境。確認螢幕關閉後感測資料是否送達。
- [ ] 實體橫放左／右各 45°，符合充電選項後鎖定；只在原 5 秒內穩定 1.5 秒才有一次啟動或通知。
- [ ] 驗證 30°、75° 邊界；平放、20°、80°、直立、對角、面朝下與劇烈晃動不觸發。
- [ ] 解鎖使用其他 App 時旋轉、插線、放上無線充電器，不開啟時鐘、不掃描。
- [ ] 鎖定超過 5 秒才調整姿勢，沒有新自動嘗試；下一次實際解鎖再鎖定才重新待命。
- [ ] Wireless Only 拒絕 USB/AC；Any Power 接受 USB/AC/Wireless/Dock；不要求充電時其他條件仍必要。充滿電但仍接通電源應依 plug source 判定。
- [ ] 掃描途中解鎖／關閉監看／系統停止服務，感測器與 wake lock 均釋放；沒有重試或常駐 sensor listener。
- [ ] 上鎖後按電源回到仍鎖定的畫面，不延長期限；真正 USER_PRESENT 清除週期。
- [ ] PIN／密碼／指紋仍由系統處理，時鐘沒有解除 keyguard。從通知點擊後若系統先要求解鎖，原工作階段拒絕在解鎖後自動出現。
- [ ] 返回、右上角退出、底部 80 dp 向上長滑正常；短移動不退出，UI Lock 與媒體頁不阻止退出。
- [ ] 手動退出、逾時、Dream 被系統重啟、服務／程序重建，不會在同一鎖定週期重新啟動。
- [ ] 強制停止後需明確恢復監看；已啟用的監看可在開機或服務重啟後恢復，但開機本身不掃描或開啟時鐘。

## Foldable regression

- [ ] 現有折疊機鉸鏈 30°–120° 仍進入；大於 150° 或小於等於 5° 仍退出並重設裝置狀態。
- [ ] Honor／Samsung／Xiaomi 等既有覆寫、雙重 reset 與導覽列處理依原能力運作；沒有新增特權聲稱。
- [ ] 非折疊手機原有手動旁路、SINGLE 與三種錶盤家族及各錶盤樣式可用。

## 拖曳、媒體與畫面

- [ ] 分隔線拖曳 20%–80% 連續更新，放開於 30/50/70% 附近 ±5 百分點才吸附；50/50 保留上一側。
- [ ] 跨中央後時鐘仍在使用者選擇的一側；設定切換左右保留分隔比例，兩個 pager／錶盤內部狀態不重設；重開後比例與側別保留。
- [ ] 垂直滑動月曆、天氣、媒體正常；分隔線、媒體 seek 與底部退出不互搶手勢。
- [ ] UI Lock 禁止調整與媒體操作，退出按鈕仍可用；TalkBack／鍵盤可操作分隔線。
- [ ] 各支援語言、加大字體、20% 窄面板與異常長曲名沒有不可操作的截斷。
- [ ] 授權通知存取後，Spotify／YouTube Music 等真實播放器能切換曲目與狀態；多播放器時選擇正在播放者。
- [ ] 停止、關閉播放器、取消授權、缺少 metadata、未知 duration、沒有 cover 均不崩潰；不支援的 actions 不顯示為可用。
- [ ] 封面完整等比例、延伸部分鏡像且模糊，原封面清晰；換曲無黑色閃爍；重複換曲與鎖定／解鎖無持續記憶體增長。
- [ ] 鎖定時完整顯示曲名、演出者、封面及進度，標準媒體控制可操作；舊的隱藏設定不生效，UI Lock 仍可停用控制，系統設定需先解鎖。
- [ ] 月曆／天氣、亮度／逾時、全螢幕與 OLED 防烙印保持可用；背景時無無用的 UI 查詢／渲染。

## 2.0.2 行程與低電量

- [ ] 點擊行程可看完整標題、開始／結束、地點、行事曆與說明；長內容可捲動，開啟外部行事曆對應到正確時段。
- [ ] UI Lock、鎖定裝置、撤銷行事曆權限或刪除行程時，不保留可操作的過期詳細資訊。
- [ ] 低於設定門檻才觸發保護，剛好等於門檻不觸發；接上電源時不觸發。
- [ ] 降亮度限制在 8%，保留原先更暗的手動設定；充電／恢復後還原，不改系統亮度。
- [ ] 低電量退出關閉時鐘與監測；回到原引導頁、解鎖或服務重建不會在低電量時恢復監測。
- [ ] 控制面板占 30–40% 高度、封面接縫沒有黑色圓角、進度點置中對齊、底部退出提示條厚度 2 dp。

## DreamService

- [ ] 系統可選擇 Linzin Desk Clock；只在實際觀察到的鎖定 5 秒剩餘期限內偵測或等待既有監看結果。
- [ ] 同時開啟監看時，共用同一次掃描，不會搶掉 Dream 或另開 5 秒期限。
- [ ] 廠商太晚啟動 Dream、沒有 lock event、未符合姿勢或充電條件時結束，維持系統畫面。
- [ ] Dream 退出／wake／解鎖時同步取消掃描、清除 Compose 生命周期及相關視窗資源。

## 開發者檢查（僅隔離測試裝置）

可用 Android Studio Profiler、dumpsys sensorservice、dumpsys power 與 logcat 檢查 listener、5 秒 wake-lock 上限及崩潰。這些只作驗證，不用來取得新權限。完整互動測試條件見建置驗證文件；自動化腳本僅使用隔離模擬器。

## 閒置關屏

- [ ] 設定有限逾時且授予僅鎖定權限後，完整等待逾時，螢幕真正關閉。
- [ ] 未授權或撤銷後會退出及釋放保持喚醒，提示由系統逾時處理。
- [ ] 背景及設定視窗不會計時鎖定其他前景 App；返回後重新計時。
- [ ] 關屏後不會在同一週期重新喚醒；實際解鎖後下一次鎖定仍可啟動。
- [ ] 系統要求 PIN／圖案／密碼的行為有清楚說明，使用者可撤銷管理員授權。
